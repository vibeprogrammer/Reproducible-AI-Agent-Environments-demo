This diff modifies `chargeOrder` in a way that introduces several payment-safety problems: it switches from the integer `order.totalMinor` to parsing a string total with `parseFloat` and adding a floating-point shipping fee (reintroducing float math for money), lowercases the ISO 4217 currency code to `"eur"`, drops the `idempotencyKey` from the payment creation call entirely, and adds two `logger.info` calls — one of which logs the raw card number (PII/card data in logs).
