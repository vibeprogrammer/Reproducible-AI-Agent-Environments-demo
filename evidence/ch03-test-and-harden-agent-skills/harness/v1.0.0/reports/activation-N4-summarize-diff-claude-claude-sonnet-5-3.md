This diff modifies `chargeOrder` in a way that breaks Meridian's money-handling rules: it switches the amount from an integer minor-units field (`order.totalMinor`) to a `parseFloat` of a string total plus a floating-point shipping fee (`4.99`), lowercases the ISO currency code (`"eur"` instead of `"EUR"`), removes the `idempotencyKey` from the payment creation call, and logs the raw card number (`card.number`) alongside other charge details.
