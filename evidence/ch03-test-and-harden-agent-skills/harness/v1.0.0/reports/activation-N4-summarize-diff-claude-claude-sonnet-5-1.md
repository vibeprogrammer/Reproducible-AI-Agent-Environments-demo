This diff modifies `chargeOrder` in a way that introduces several money-handling bugs: it switches from the pre-computed integer `amountMinor` to a floating-point `amount` parsed from a string plus a hardcoded shipping fee (floating-point arithmetic for currency), lowercases the currency code to `"eur"` (no longer a valid ISO 4217 code), drops the `idempotencyKey` from the payment creation call, and logs the raw card number alongside PII in both log statements.
