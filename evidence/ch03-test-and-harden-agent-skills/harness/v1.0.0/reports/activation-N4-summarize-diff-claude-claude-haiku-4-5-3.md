This diff modifies the `chargeOrder` function in a payment checkout flow. It changes the amount handling from using integer minor units (`order.totalMinor`) to floating-point arithmetic (`parseFloat(order.total) + 4.99`), converts the currency code to lowercase, removes the idempotency key from the payment creation, and adds logging that exposes sensitive card data (the card number). These changes violate payment handling best practices around amount representation, idempotent transactions, and PII protection.
