The diff modifies the `chargeOrder` function to switch from using integer minor units to floating-point arithmetic, add a hardcoded shipping fee, log the card number (PII), change the currency code to lowercase, and remove the idempotency key. However, these changes violate multiple of Meridian's money rules: amounts must be integers in minor units, every payment call needs an idempotency key, no card data should be logged, and currency codes must be uppercase ISO 4217 format.
