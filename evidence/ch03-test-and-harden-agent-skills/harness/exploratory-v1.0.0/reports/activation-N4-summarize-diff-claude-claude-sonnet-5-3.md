`change.diff` modifies `src/checkout/charge.ts` in a way that introduces several money-handling bugs: it switches the charge amount from the integer `order.totalMinor` to a floating-point `parseFloat(order.total)` plus a hardcoded `shippingFee` of 4.99 (floating-point arithmetic for currency), lowercases the currency code to `"eur"` (invalid ISO 4217), removes the `idempotencyKey` from the payment creation call, and adds logging of the raw card number (`card.number`) alongside payment details — logging sensitive card/PII data.
