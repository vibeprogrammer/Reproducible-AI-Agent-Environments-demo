# meridian-role-platform

Role bundle for Meridian platform engineers who own CI and release
workflows. It adds one instruction on top of the baseline package
`meridian-engineering-standards`; it does not include the baseline itself.

- Owner: `meridian-finance/platform-team` (Jon is the maintainer).
- Consume it beside the baseline, pinned to
  `meridian-role-platform-v1.0.0`.

Part of the companion demos for Chapter 10 of *Reproducible AI Agent
Environments*. Meridian and `meridian-finance` are fictional.
